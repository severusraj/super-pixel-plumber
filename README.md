# 🍄 Super Pixel Plumber

A playable, Mario-inspired 2D side-scrolling platform game built with **HTML5 Canvas, CSS, and vanilla JavaScript**. No framework, build step, backend, or dependencies required.

## 🎮 Play locally

Open `index.html` in any modern desktop or mobile browser.

## 🕹️ Controls

| Key | Action |
| --- | --- |
| `←` / `→` or `A` / `D` | Move |
| `Space`, `↑`, or `W` | Jump |
| `Shift` | Sprint |
| `P` or `Esc` | Pause |
| `R` | Restart |
| `M` | Toggle sound |

On mobile, use the on-screen touch controls.

## ✨ Features

- Two side-scrolling worlds
- Coins, enemies, and score tracking
- Mushroom power-ups and interactive blocks
- Checkpoints and finish flags
- Retro sound effects
- Responsive design and touch support

## 🚀 Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Select **Other** (or leave Framework Preset as **Other**).
3. Leave build command blank and publish the repository root.
4. Click **Deploy**.

This is a standalone static site, so `index.html` is served automatically.

## 🌐 Deploy to GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and the root (`/`) folder, then save.
